# AL WAREEN Corporate Website — Version 2

A redesigned, multi-page, bilingual corporate website for AL WAREEN.

## Pages
- `index.html` — Home
- `about.html` — About Us
- `services.html` — Six business divisions
- `industries.html` — Industries and potential markets
- `contact.html` — Contact details (no contact form)

## Version 2 updates
- Distinct Saudi architecture / skyline hero photography on every page.
- Added Real Estate as the sixth business division.
- Added Real Estate & Property to the potential markets section.
- Updated home page service cards and footer navigation to include Real Estate.
- New premium visual system with richer full-bleed photography, animated hero zoom, refined typography and stronger editorial layouts.
- English / Arabic language switcher with LTR / RTL layout on every page.
- Original supplied AL WAREEN logo used unchanged in header and footer, plus favicon.
- All email links use `mailto:ceo@alwareen.com`. No contact form or invented phone/address/social details.

## Preview locally
Open `index.html` or serve the folder:
```bash
python3 -m http.server 8000
```
Visit `http://localhost:8000`.

## Production checklist
- Confirm image licensing and host approved photography locally before production.
- Review Arabic translations and all corporate/service wording with an authorized company representative.
- Confirm the exact Real Estate scope and applicable licenses before publishing detailed property service claims.
- Configure domain, HTTPS, hosting, privacy/legal pages and any required analytics consent.
